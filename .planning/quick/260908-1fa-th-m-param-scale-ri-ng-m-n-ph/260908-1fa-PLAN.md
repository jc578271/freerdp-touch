<objective>
Give the external display an independently configurable remote Windows desktop scale in the existing `/multimon` session while preserving the OneMix primary monitor at 200% and the established OneMix-only path.

Purpose: The existing `/scale-desktop:200` is stored by FreeRDP as one global setting. The feature must instead populate the already-supported per-monitor `rdpMonitor.attributes.desktopScaleFactor` values that FreeRDP serializes in its monitor-layout data.

Output: One integrated Debian quilt-patch update, an `FREERDP_EXTERNAL_DESKTOP_SCALE` launcher parameter with a 100% default, focused production and rendered-xinitrc regressions, and operator guidance.

Discovery level: 1. Local FreeRDP 3.15 source inspection established that `/scale-desktop` writes one `FreeRDP_DesktopScaleFactor`, whereas `rdpMonitor.attributes.desktopScaleFactor` is serialized per monitor in both GCC monitor-extended data and `DISPLAY_CONTROL_MONITOR_LAYOUT`. The existing Debian rules enable `BUILD_TESTING=ON`, so an X11 CTest registered in the current patch runs during a normal release build without adding a dependency.
</objective>
