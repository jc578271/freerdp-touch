**1. xf_touch_force_cancel function (xf_input.c)**

Add a non-static function `void xf_touch_force_cancel(xfContext* xfc)` in xf_input.c. It does:
- Get `rdpClientContext* cctx = &xfc->common` and `RdpeiClientContext* rdpei = cctx->rdpei`.
- Iterate `cctx->contacts[i]` for i=0 to FREERDP_MAX_TOUCH_CONTACTS-1 (the authoritative native store, include/freerdp/client.h:137 — NOT xfc->contacts[] which is the local-gesture array, xfreerdp.h:304).
- For each slot where `cctx->contacts[i].id != 0` (active slot):
  - If `rdpei != NULL`: call `rdpei->TouchCancel(rdpei, cctx->contacts[i].id, cctx->contacts[i].x, cctx->contacts[i].y, &dummy)` where `int dummy = 0`. This emits UP|CANCELED per rdpei_main.c:1192.
  - Record the canceled ID: add `cctx->contacts[i].id` to `xfc->canceledIds[xfc->canceledIdCount++]` (D-07 idempotency set).
  - Record the finger for the recovery gate: add `cctx->contacts[i].id` to `xfc->quarantinedFingers[xfc->quarantinedCount++]` (D-08).
  - Clear the slot: `FreeRDP_TouchContact empty = { 0 }; cctx->contacts[i] = empty;` (same pattern as client.c:1929-1934).
- If any contacts were canceled, set `xfc->recoveryGateArmed = TRUE`.
- If no contacts were active, this is a no-op (empty iteration, no IDs recorded, gate not armed).
