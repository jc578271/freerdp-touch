Create `README.md` as the single operations guide for the FreeRDP Touch for OneMix 3 release. Use sanitized examples — no real IPs, passwords, or usernames (D-06, D-19). Structure:

1. **Prerequisites**: Native X11 session (GNOME on Xorg), Debian trixie, `sudo apt install quilt`, `sudo apt build-dep freerdp3`. Reference `scripts/check-x11-session.sh` for session verification.

2. **Build the patched package**: Run `./scripts/build-release.sh`. Explain it extracts a fresh pinned source tree, applies `patches/onemix-touch.patch`, builds via `dpkg-buildpackage`, and produces `dist/` with the 4-package closure + `SHA256SUMS`. State the version: `3.15.0+dfsg-2.1+deb13u3+onemix1` (D-07).

3. **Install**: Document the exact install command for the 4-package closure from `dist/`:
   `sudo apt install -y --allow-downgrades ./dist/libwinpr3-3_*_amd64.deb ./dist/libfreerdp3-3_*_amd64.deb ./dist/libfreerdp-client3-3_*_amd64.deb ./dist/freerdp3-x11_*_amd64.deb`
   Install in one transaction; never use a `freerdp3-*.deb` glob (D-10, D-12). Verify: `dpkg-query -W -f='${Package} ${Version}\n' freerdp3-x11 libfreerdp-client3-3 libfreerdp3-3 libwinpr3-3` — all must show `+onemix1`. Run `sha256sum -c dist/SHA256SUMS` before installing.

4. **Launch — normal daily mode**: `scripts/launch-touch.sh <connection-args>` or via menu option 3. Explain defaults: long-press 600ms, slop 8px (D-13, D-17). No +multitouch (D-01).

5. **Launch — diagnostic mode**: `FREERDP_TOUCH_DIAG=1 scripts/launch-touch.sh <connection-args>`. Logs to `${XDG_STATE_HOME:-$HOME/.local/state}/freerdp-touch/`. Compact touch/gesture/RDPEI records on stderr and in the log file (D-03, D-04, D-05, D-21).

6. **Calibration overrides**: `FREERDP_TOUCH_LONG_PRESS_MS=650 FREERDP_TOUCH_SLOP_PX=10 scripts/launch-touch.sh <connection-args>`. Long press 500-700, slop 4-16. Invalid values fail before launch (D-15, D-16).

7. **Mouse-only escape hatch**: `scripts/launch-touch.sh --mouse-only <connection-args>`. Omits all touch options; same patched binary, no rollback needed (D-20).

8. **Roll back to stock**: 
   `sudo apt install --reinstall -y freerdp3-x11 libfreerdp-client3-3 libfreerdp3-3 libwinpr3-3`
   If that fails (version conflict): `sudo apt install -y freerdp3-x11/trixie libfreerdp-client3-3/trixie libfreerdp3-3/trixie libwinpr3-3/trixie`
   Verify: `dpkg-query -W -f='${Package} ${Version}\n' freerdp3-x11` — must NOT show `+onemix1` (D-12).

9. **Security-update replacement**: A future `apt upgrade` may replace the local `+onemix1` build with a newer Debian version — this is expected and preferred (D-08). Detect: `dpkg-query -W -f='${Version}' freerdp3-x11 | grep -q onemix1 || echo "Touch patch no longer installed — rebuild on newer source if needed."` To rebuild: update the pin in `build-release.sh` to the new Debian version, re-extract, re-apply the patch (may need manual conflict resolution), rebuild, reinstall. No apt hold or pin is used (D-08).

10. **What NOT to expect**: No native multitouch/RDPEI forwarding (D-01). No runtime mode switching (v2). No on-the-fly classifier tuning (D-14). No config file (D-15). No daemon.

All command examples use placeholder connection args like `<connection.rdp>` or `/v:your-host /u:your-user` — never real credentials (D-06, D-19).
