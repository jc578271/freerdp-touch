**STEP 1 — Create build/freerdp3-3.15.0+dfsg/client/X11/xf_touch_internal.h:**
A self-contained header with static inline pure helpers. Include only `<math.h>` and `<stddef.h>` — no X11 or FreeRDP headers, so tests compile it standalone. Define these helpers:

1. `xf_classify_two_finger(double pinchDelta, double panDelta, double panDb, double deadbandPx, double dominanceRatio)` returning int (0=PENDING, 1=PINCH, 2=SCROLL). Pure classifier decision.
2. `xf_quarantine_add(int* fingers, int count, int fingerId, int maxContacts)` returning int (new count). Dedup check, bounds check.
3. `xf_gate_derive(int count)` returning int. Returns count > 0.
4. `xf_bounds_admit(int is_begin, int x, int y, int left, int top, int right, int bottom)` returning int (1=admit, 0=reject). Only rejects Begin outside bounds; Update/End always admitted.
5. `xf_pinch_emit_steps(double* accum, double step)` returning int (signed wheel event count). Uses fabs; does NOT add delta — caller adds delta first.
6. `typedef struct { int touchId; int x; int y; int active; } xfDiagContact;` and lifecycle functions: `xf_diag_contact_begin` (inserts or refreshes on duplicate Begin without incrementing count), `xf_diag_contact_update` (refreshes x/y), `xf_diag_contact_end` (retires slot, decrements count).
7. `typedef enum { XF_FC_PHASE_DIAG_CANCEL = 0, XF_FC_PHASE_SUMMARY, XF_FC_PHASE_NATIVE_CANCEL, XF_FC_PHASE_GESTURE_CLEAR } xfFcPhase;` and `typedef void (*xfFcEmitCb)(xfFcPhase phase, int touchId, int x, int y, int diag_count, int native_count, int quarantined, void* ctx);`
8. `xf_force_cancel_emit_sequence(...)` remains a pure, production-called ordering helper. It snapshots active diagnostic contacts, emits DIAG_CANCEL callbacks at their last coordinates, emits one SUMMARY carrying the exact snapshot/native/quarantine counts, emits native cancellations, then emits GESTURE_CLEAR. It returns the diagnostic snapshot count and does not own `xfContext` storage.
9. Add one production-used `xf_quarantine_update` helper as the sole runtime owner of the live quarantine array, count, and gate after initialization. Give it explicit add-set and consume-End operations: add preserves existing IDs and deduplicates/bounds-checks each input; consume removes one matching ID; every operation assigns the gate from the final count. Route pinch cleanup, pending/scroll/middle-button first-lift cleanup, force-cancel merge, and recovery-gate End through this owner. `tests/xf_touch_internal_check.c` calls the same owner; do not create a test-only lifecycle model.
