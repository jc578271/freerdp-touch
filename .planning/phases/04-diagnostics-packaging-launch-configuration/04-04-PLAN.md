**STEP 1 — Create build/freerdp3-3.15.0+dfsg/client/X11/xf_touch_internal.h:**
A self-contained header with static inline pure helpers. Include only `<math.h>` and `<stddef.h>` — no X11 or FreeRDP headers, so tests can compile it standalone. Define:

1. `xf_classify_two_finger(double pinchDelta, double panDelta, double panDb, double deadbandPx, double dominanceRatio)` returning int (0=PENDING, 1=PINCH, 2=SCROLL). The pure classifier decision: if pinchDelta >= deadbandPx AND pinchDelta > dominanceRatio * panDelta, return PINCH; if panDelta >= panDb, return SCROLL; else PENDING. Constants are parameters so production passes its #define values and tests pass values extracted from the source.

2. `xf_quarantine_add(int* fingers, int count, int fingerId, int maxContacts)` returning int (new count). Dedup check: if fingerId already in fingers[0..count-1], return count unchanged. Bounds check: if count < maxContacts, fingers[count++] = fingerId. Return count.

3. `xf_gate_derive(int count)` returning int. Returns count > 0. Always derives the armed flag from the count.

4. `xf_bounds_admit(int is_begin, int x, int y, int left, int top, int right, int bottom)` returning int (1=admit, 0=reject). If is_begin AND (x < left || x >= right || y < top || y >= bottom), return 0. Else return 1.

5. `xf_pinch_emit_steps(double* accum, double step)` returning int (signed wheel event count: +=up, -=down). Does NOT add delta — the caller adds delta to accum first, then calls this. While fabs(*accum) >= step: if *accum > 0.0, events++, *accum -= step; else events--, *accum += step. Return events.

6. `typedef struct { int touchId; int x; int y; int active; } xfDiagContact;`

7. `xf_diag_contact_begin(xfDiagContact* contacts, int count, int touchId, int x, int y, int maxContacts)` returning int (new count). First: scan all maxContacts slots for an active entry with matching touchId — if found, refresh its x and y and return count UNCHANGED (duplicate Begin refreshes without incrementing). Second: scan for an inactive slot — if found, set touchId/x/y/active=1 and return count+1. If no free slot, return count.

8. `xf_diag_contact_update(xfDiagContact* contacts, int maxContacts, int touchId, int x, int y)` returning void. Scan for active entry with matching touchId — if found, refresh x and y. If not found, no-op (touch was rejected at Begin).

9. `xf_diag_contact_end(xfDiagContact* contacts, int count, int touchId, int maxContacts)` returning int (new count). Scan for active entry with matching touchId — if found, set active=0 and return count-1. If not found, return count unchanged.
