  <action>
Create `scripts/launch-touch.sh` as a Bash script (Bash is required for arrays and PIPESTATUS[0] — Pitfall 5). The wrapper owns ONLY the local-touch preset; all FreeRDP connection/session arguments pass through unchanged via `"$@"`.

Structure:
1. Shebang `#!/usr/bin/env bash`, `set -eu`.
2. Parse `--mouse-only` from `$@`: if present, shift it out and set a flag. All remaining args are FreeRDP connection/session arguments passed unchanged (D-20).
3. Validate calibration overrides (D-15, D-16):
   - `FREERDP_TOUCH_LONG_PRESS_MS`: default 600. Accept only unsigned decimal digits. Range 500-700. Reject non-digits or out-of-range with a clear stderr message and exit 1 before invoking FreeRDP.
   - `FREERDP_TOUCH_SLOP_PX`: default 8. Accept only unsigned decimal digits. Range 4-16. Reject non-digits or out-of-range with a clear stderr message and exit 1.
   - Validation must use a digits-only check (e.g., `case "$val" in *[!0-9]*|'') reject;; esac`) and arithmetic comparison (`[ "$val" -ge 500 ] && [ "$val" -le 700 ]`). Never use eval (Pitfall 6, ASVS V5).
4. Compose touch args as a Bash array (D-01, D-15):
   - Non-mouse-only: `touch_args=("+touch-pinch-wheel-fallback" "/touch-long-press:${lp_ms}" "/touch-slop:${slop_px}")`
   - Mouse-only: `touch_args=()` (omit all touch options — D-20)
   - Never include `+multitouch` (D-01, Pitfall 3).
5. Run the native-X11 gate: `./scripts/check-x11-session.sh` (or resolve the sibling script path relative to the wrapper location). Fail closed if not native X11.
6. Normal mode (FREERDP_TOUCH_DIAG unset or not "1"): `exec /usr/bin/xfreerdp3 "${touch_args[@]}" "$@"` — direct exec, no tee, no subshell (D-05).
7. Diagnostic mode (FREERDP_TOUCH_DIAG=1):
   - Create log directory: `log_dir="${XDG_STATE_HOME:-$HOME/.local/state}/freerdp-touch"`; `mkdir -p "$log_dir"`; `umask 077` (D-06).
   - Create timestamped log: `log_path="$log_dir/touch-$(date +%Y%m%dT%H%M%S).log"` (D-05, D-06).
   - Run with tee: `/usr/bin/xfreerdp3 "${touch_args[@]}" "$@" 2>&1 | tee "$log_path"`; `exit "${PIPESTATUS[0]}"` (Pitfall 5: preserve client exit status, not tee's).
   - Do NOT echo the constructed command, do NOT set WLOG_LEVEL=DEBUG, do NOT enable shell xtrace (D-05, D-06, Pitfall 6).
8. The wrapper must NOT read, store, prompt for, or echo passwords or connection credentials (D-19). FreeRDP's existing prompt handles authentication.

Make the script executable: `chmod +x scripts/launch-touch.sh`.

Verify with a dry-run mock: create a temporary fake `xfreerdp3` that echoes its args to stderr and exits 0. Run the wrapper against it with: (a) no overrides (expect 600/8), (b) valid overrides (expect custom values), (c) non-integer override (expect rejection), (d) out-of-range override (expect rejection), (e) --mouse-only (expect no touch args), (f) FREERDP_TOUCH_DIAG=1 (expect log file created). Assert the composed args contain +touch-pinch-wheel-fallback and no +multitouch in all non-mouse-only cases.
