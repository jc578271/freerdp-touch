<objective>
Implement the long-press right-click gesture with a motion deadband that fixes the on-device root cause (1-3px X11 jitter cancels Windows press-and-hold), plus extend the single xf_touch_force_cancel reset seam to clear all Phase 3 gesture state and release a held Ctrl idempotently, plus wire the three configurable settings and CLI knobs.

Purpose: This is the highest-value Phase 3 item — the Phase 2 on-device UAT confirmed the root cause (jitter forwards as RDPEI MOTION, Windows cancels its own press-and-hold). The client-owned long-press with slop suppression both fixes the jitter leak and owns the right-click timing so it no longer depends on Windows. Extending the single reset seam here gives every lifecycle hook (FocusOut, ConfigureNotify, UnmapNotify, toggle_fullscreen, post_disconnect) gesture cleanup + Ctrl release for free, which is the STAB-01 foundation plans 02 and 03 build on.

Output: Long-press state machine inline in xf_input_touch_remote, extended xf_touch_force_cancel, xf_input_OnTimer deadline callback, all Phase 3 gesture fields in xfreerdp.h, three settings rows + three CLI cases, a building tree.
</objective>
